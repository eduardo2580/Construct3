## 🎮 About Construct 3

Construct 3 is a browser-based game development engine that allows games to be created using visual event-based programming.

Construct 3 es un motor de desarrollo de videojuegos basado en navegador que permite crear juegos mediante programación visual basada en eventos.

Construct 3 é uma ferramenta de desenvolvimento de jogos baseada em navegador que permite criar jogos usando programação visual baseada em eventos.
